Nutrilite-calorie count

NutriLite is a full-stack calorie and nutrition tracking web application that leverages real-time data from the USDA FoodData Central API to help users log meals, track calories and macronutrients, and analyze daily nutrition trends. The application is built with React and Vite on the frontend and Node.js with Express on the backend. Secure user authentication and session management are implemented using Supabase, enabling personalized meal tracking and data persistence.

Tech: React, Vite, HTML5, CSS3, JavaScript (ES6+), Node.js, Express.js, USDA FoodData Central API, REST APIs, Local Storage, Git, Netlify
